# Sentera Camera Integration Tools

This repository is a resource for customers and integrators looking for scripts that can help integrate Sentera cameras into their projects. The examples demonstrate camera communication and common workflows that can be adapted to your application.

## Available scripts

- [`test-api/`](test-api/): camera API and ROS bridge examples. See the [test-api guide](test-api/README.md) for setup, connection instructions, message examples, and usage of the 6X camera control script.
